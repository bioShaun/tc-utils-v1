# snpeff_extract.py - VCF注释提取脚本分析

## 代码概览

**文件路径**: vcf/snpeff_extract.py

**功能描述**: 从VCF文件中提取snpEff注释信息，选择每个位点优先级最高的注释并输出为TSV格式。

**核心逻辑**: 根据影响级别优先级(HIGH > MODERATE > LOW > MODIFIER)筛选最关键的变异注释。

## 代码结构分析

### 优点

1. **清晰的模块化设计**
   - 使用`@dataclass`定义数据结构(`AnnEntry`)，使代码更易读和维护
   - 功能明确分离：数据解析(`parse_ann`) → 数据规范化(`normalize_ann_values`) → 最佳注释选择(`pick_best_annotation`)

2. **优秀的类型注解**
   - 完整使用`typing`模块中的类型提示
   - `from __future__ import annotations`支持前瞻性类型注解
   - 所有函数都有清晰的参数和返回类型标注

3. **合理的依赖管理**
   - 使用`cyvcf2`进行高效的VCF文件读取
   - 使用`loguru`进行结构化日志记录
   - 使用`tqdm`提供进度条反馈
   - 使用`typer`构建命令行接口

4. **健壮的错误处理**
   - 对可能为空或格式错误的数据进行防御性检查
   - 使用可选类型(`Optional`)明确表示可能的空值情况
   - 记录处理统计信息(total, missing counts)

### 设计模式亮点

1. **常量定义** (第21-22行)
   ```python
   IMPACT_PRIORITY = ["HIGH", "MODERATE", "LOW", "MODIFIER"]
   IMPACT_RANK = {impact: rank for rank, impact in enumerate(IMPACT_PRIORITY)}
   ```
   - 使用字典映射实现快速查找优先级，避免重复的字符串比较

2. **数据规范化函数** (第34-45行)
   - 统一处理不同格式的ANN数据(可能是字符串、列表或元组)
   - 通过`split(",")`处理可能包含逗号分隔的复合值

3. **选择算法的简洁实现** (第64-72行)
   - 使用单次遍历算法，时间复杂度O(n)
   - 初始化时设置`best_rank`为超出范围的数值，简化比较逻辑

## 性能特点

1. **流式处理**: 使用`cyvcf2`的迭代器避免将整个VCF加载到内存
2. **单次遍历**: `pick_best_annotation`算法只需要一次遍历注释列表
3. **内存友好**: 按记录处理，不累积大量数据

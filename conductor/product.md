# Initial Concept
A collection of Python scripts and tools commonly used in bioinformatics pipelines, organized by module (e.g., vcf, fasta, primer).

# Product Guide

## Target Audience
- **Bioinformaticians and Computational Biologists:** The primary users who will integrate these scripts into their research and production pipelines.

## Core Goals
- **Centralization:** Maintain a single source of truth for frequently used bioinformatics utilities to avoid duplication of effort.
- **Standardization:** Establish a common set of tools to ensure consistent data processing results across various projects and team members.
- **Efficiency:** Optimize processing of large-scale genomic data formats (VCF, FASTA, BED, etc.) using high-performance libraries like Polars and Cyvcf2.

## Key Domains & Formats
- **Variant Analysis:** Specialized tools for VCF manipulation, filtering, and genotype statistics.
- **Sequence Processing:** Utilities for FASTA/FASTQ handling, including sequence extraction and rewriting.
- **Genomic Annotations:** Robust support for interval-based formats like BED, GTF, and GFF.

## Documentation Standards
- **Comprehensive Guidance:** Each script should be accompanied by detailed documentation, including clear input/output examples and thorough descriptions of all parameters to ensure accessibility and reproducibility.

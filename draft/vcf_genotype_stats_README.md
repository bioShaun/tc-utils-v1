# VCF基因型统计工具

这是一个用于分析VCF文件中基因型分布的Python脚本，能够统计每个位点的：
- **纯合REF型** (0/0)：两个等位基因都是参考等位基因
- **杂合型** (0/1, 1/0, 0/2, 1/2 等)：两个等位基因不同
- **纯合ALT型** (1/1, 2/2, 3/3 等)：两个等位基因都是替代等位基因

## 依赖

- Python 3.7+
- typer
- cyvcf2
- tqdm
- numpy

## 安装依赖

```bash
pip install typer cyvcf2 tqdm numpy
```

或者使用项目的requirements.txt：

```bash
pip install -r /path/to/requirements.txt
```

## 使用方法

### 基本用法

```bash
# 分析VCF文件并显示统计结果
python vcf_genotype_stats.py input.vcf

# 指定输出文件保存详细结果
python vcf_genotype_stats.py input.vcf --output results.csv

# 显示前10个位点的详细信息
python vcf_genotype_stats.py input.vcf --show-sites

# 组合使用
python vcf_genotype_stats.py input.vcf --output results.csv --show-sites
```

### 命令行选项

- `VCF_FILE`：输入VCF文件路径（必需）
- `--output, -o`：可选的CSV输出文件路径，用于保存每个位点的详细统计
- `--show-sites`：显示前10个位点的详细信息

## 输出说明

### 控制台输出

1. **总体统计**：
   - 总位点数
   - 总样本数
   - 基因型数量统计
   - 基因型频率百分比

2. **按染色体统计**：
   - 每个染色体的基因型分布

### CSV输出文件

如果指定了 `--output` 参数，脚本会生成一个CSV文件，包含以下列：

- `CHROM`：染色体
- `POS`：位置
- `REF`：参考等位基因
- `ALT`：替代等位基因
- `hom_ref`：纯合REF样本数
- `het`：杂合样本数
- `hom_alt`：纯合ALT样本数
- `total_samples`：总样本数

## 功能特点

1. **高效处理**：使用cyvcf2库快速读取VCF文件
2. **进度显示**：使用tqdm显示处理进度
3. **多层级统计**：
   - 全局统计
   - 按染色体统计
   - 位点级别详细统计
4. **输出灵活**：控制台显示汇总，CSV保存详细结果
5. **错误处理**：友好的错误提示和异常处理
6. **命令行友好**：完整的typer CLI界面，支持自动补全

## 基因型编码说明

VCF文件中的基因型使用数字编码：
- `0`：参考等位基因 (REF)
- `1, 2, 3, ...`：替代等位基因 (ALT1, ALT2, ALT3, ...)

基因型格式：
- `0/0` 或 `0|0`：纯合REF
- `1/1` 或 `1|1`：纯合ALT（第一个ALT）
- `0/1`, `1/0`, `0/2`, `1/2` 等：杂合型
- `|` 表示相位信息，`/` 表示无相位信息，脚本会同时处理两种格式

## 注意事项

1. 脚本会自动跳过缺失或无效的基因型数据
2. 多等位基因位点会被正确处理（如0/2, 1/2等）
3. 大型VCF文件可能需要较长时间处理，建议先在小文件上测试
4. 输出CSV文件可能会很大（取决于位点数和样本数）

# splitBed.py

## 功能与输入输出
- 目的：按长度近似均分 BED/FAI 记录，输出多个子 BED 文件；支持普通 BED 和 FAI 两种模式（`is_bed` 参数控制）。
- 输入：BED 或 FAI；输出：在 `out_dir/<原文件名stem>/` 下生成分块后的 .bed（`split_number==1` 时创建符号链接）。

## 核心流程
- BED 模式：读取三列，计算每行长度求总长 -> 期望均分长度 = 总长//份数 -> 逐行累积，超过阈值时落盘一个块；文件名含块序和首尾坐标。
- FAI 模式：读染色体长度，按 `get_genome_split_length` 计算“规整化”的拆分长度；用步长=长度/10 扫描染色体累积到块，写出 BED。
- `save_current_bedrows` 负责组装 DataFrame 并保存，无 header/index。

## 观察与隐患
- `pad_num` 形参未使用，文件名前缀仅用 `zfill(prefix_pad_num)`；可删除或按设计补零。
- BED 模式 `bed_length_per_file = total // n` 取整可能导致后续块差异大；当第一行长度>均分长度时会立即切块，导致空列表保存风险（当前逻辑避免了空保存，但第一块会包含该大区间）。
- 当坐标含 0 时，`np.log10(max_size)` 会触发 `-inf`，后续 `ceil`/`int` 可能报错；缺少对输入坐标合法性的检查。
- FAI 模式步长 `step = genome_split_length // 10`，若 genome_split_length < 10 会得到 0，循环异常；未处理 `split_number` 非正数等非法输入。
- CLI 缺少参数说明/help，报错多为裸 `ValueError`，用户体验弱。

## 改进建议
- 明确文件名格式：若需要零填充则使用 `pad_num`，否则移除相关计算；可以加入块内条数/长度统计到文件名或伴随的 meta。
- 对输入做校验：坐标需为正且 start<end；`split_number`>0；FAI 步长最小值设为1，避免 0 步长。
- 调整均分策略：允许余数均摊或按块数预分配目标长度，减少块间差异；可考虑按总长度/块数向上取整。
- CLI 友好：为 Typer 参数添加类型和帮助，遇到输出目录已存在时提供覆盖/跳过选项。
- 可选添加日志打印各块长度分布，便于检查均衡程度。

## 测试思路
- BED 模式：小型 BED（不同长度区间）拆成 2/3 份，断言输出块数、每块区间总长不为 0、坐标保持顺序。
- FAI 模式：单染色体长度小于/大于 `split_number`*10，验证步长下限处理；多染色体混合场景检查块名与坐标连续性。
- 异常路径：`split_number`<=0、输出目录已存在、坐标含 0 或 start>=end。
